# For You, Fairfax — Joint Hub for Fairfax City Council

A community resource hub for Fairfax City Council members **Tom Hall**, **Stacy Hall**, and **Rachel**.

## Live Sites (GitHub Pages)

- **Version 1 — Civic/Government**: https://norrin302.github.io/foryoufairfax/
- **Version 2 — Bold/Editorial**: https://norrin302.github.io/foryoufairfax/v2-bold/
- **Version 3 — Editorial/Magazine**: https://norrin302.github.io/foryoufairfax/v3-editorial/
- **Version 4 — Modern Minimalist**: https://norrin302.github.io/foryoufairfax/v4-minimal/

## Choose Your Version

Each folder contains a complete static site. To switch versions:
1. Replace `index.html` in the root with the `index.html` from the version folder you want
2. Commit and push — GitHub Pages will auto-update
